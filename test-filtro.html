Test de Diagnóstico del Filtro

Instrucciones:

  1. Abre inventario.html en tu navegador
  2. Presiona F12 para abrir la consola del navegador
  3. Espera a que la página cargue completamente
  4. En la consola, ejecuta los siguientes comandos uno por uno y observa los resultados:

Comandos de Diagnóstico:

// 1. Verificar que el elemento SELECT existe
console.log('SELECT element:', document.getElementById('ordenar-por'));

// 2. Verificar que la instancia de inventario existe
console.log('Inventario instance:', window.inventario);

// 3. Verificar el orden actual
console.log('Orden actual:', window.inventario ? window.inventario.ordenActual : 'N/A');

// 4. Intentar cambiar el select manualmente
const select = document.getElementById('ordenar-por');
if (select) {
    select.value = 'descripcion-asc';
    select.dispatchEvent(new Event('change'));
    console.log('✅ Select cambiado a descripcion-asc');
} else {
    console.error('❌ SELECT NO ENCONTRADO');
}

// 5. Verificar si hay productos cargados
console.log('Productos cargados:', window.inventario ? window.inventario.productos.length : 0);

Resultados Esperados:

  • ✅ El SELECT debe existir (no debe ser NULL)
  • ✅ La instancia de inventario debe existir
  • ✅ Al cambiar el select, debería verse en consola "Ordenando por: descripcion-asc"
  • ✅ La tabla debería reordenarse automáticamente

Si alguno falla:

  • ❌ Si SELECT es NULL → El elemento no existe o no está cargado
  • ❌ Si inventario es null/undefined → El JavaScript no se cargó correctamente
  • ❌ Si no hay productos → La base de datos está vacía o no se conectó
  • ❌ Si no se reordena → El event listener no está funcionando

Por favor, ejecuta estos comandos y dime cuáles fueron los resultados exactos.
